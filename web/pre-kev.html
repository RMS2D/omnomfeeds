:: what this is ::

Pre-KEV is our own bucket. A CVE lands here when at least N distinct curated sources mention it inside the lookback window AND CISA hasn't formally added it to KEV yet. By the time KEV adds something, you've usually been in incident response for days. This list is the lead time.
We aggregate ~80 RSS feeds, vendor PSIRTs, security-side Bluesky & Mastodon, GitHub Advisories. A single source posting about a CVE doesn't trigger Pre-KEV - we need cross-source consensus. False positives get filtered by the source-count threshold.
