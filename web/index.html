:: Webhook alerts (Pro)
Get a Slack / Discord / generic webhook ping the moment something matches a rule you saved. CISA KEV catalog additions, specific CVEs, keyword matches, tag matches - all fire within a minute of the article landing in the feed.
$10/mo, founder pricing locked in for life. Self-host the open-source binary if you'd rather wire your own webhook pipeline.
:: Your alert rules
Rules fire on new articles only; dedup means the same article can't fire the same rule twice. Webhook URLs must be https://; loopback / private addresses are rejected.

:: Channels (Pro)
Save a search query as a named channel. DLL hijacking, macOS malware, my stack - each one becomes a one-click filter on the article list. Search the operator's full corpus, save the slice that matters to you.
:: Your channels
Channels show as quick-filter chips above the article list. Click one to apply its search; click again to clear.
loading...
:: Add new channel
Substring match against title + summary, case-insensitive. Same syntax as the in-app / search.
:: Personalization (Pro)
Write 1-2 sentences about what you run / what you care about ("I run a Linux web shop in fintech, my team owns SIEM"). Click Personalize my feed and the AI re-sorts the visible list so the things YOU care about float to the top - on top of the keyword scoring.
:: Your profile
Plain text. 1-2 sentences. Mention your tech stack, role, threat model, and what you specifically care about. The shorter and more specific, the better the re-ranking.
:: Your stack
Comma-separated keywords for the tech you actually run. Articles that mention any keyword get tagged yours:<keyword> so they stand out in the feed. No AI cost - simple word-boundary match on title, summary, and existing tags.
:: ATT&CK Navigator export
Download a MITRE ATT&CK Navigator layer JSON showing TTP frequency across your bookmarked articles. Paste into attack-navigator → Open Existing Layer → Upload from local to see a coverage heat-map.
⬇ My bookmarks layer Global (30d) Global (90d)
:: Patch Tuesday alerts
Calendar-pinned vendors auto-brief on patch days. Toggle which vendors you want to see briefs for. Defaults: MS + Adobe + Oracle on (calendar-pinned); Apple + Linux + Browser off (threshold-triggered, coming soon).
:: Email digest
Drop the daily AI brief into your inbox so you don't have to remember to open the app. Same content as the in-app brief; delivered via Resend.
:: REST API access (Pro)
Generate bearer tokens for the read API: pipe articles into Splunk, Sigma, your SIEM, a CI workflow, or whatever you want. Tokens authenticate the same surface your browser session can hit (read articles, mark read, bookmarks, watched accounts).
$10/mo, founder pricing locked in for life.
:: Your API tokens
Use the Authorization: Bearer <token> header to authenticate to https://omnomfeeds.com/api/*. The full token is shown once at creation; we only store its SHA-256 hash. Lost it? Delete and mint a new one.
