02
// why a worm

Reading every security RSS feed by hand is a tax on your day. A bookmark folder of 50 sites is a guilt machine. oM noM does the firehose part for you: pulls everything, scores each item against weighted keyword categories, auto-flags anything in the CISA KEV catalog, deduplicates noise, and shows you the 5% worth your attention.

Single Go binary. Runs entirely on your machine. SQLite for state. No telemetry. No proxy. All API calls go direct from your machine to the source.

03
// features (all tiers)
50+ curated sources
RSS, Reddit, Mastodon, GitHub Security Advisories, MalwareBazaar, Bluesky search + watched accounts. 107-handle curated picker for security researchers.
MITRE ATT&CK coverage
Every article gets technique tags. A modal shows which ATT&CK techniques are dominating today's feed; click to filter.
CISA KEV auto-flagging
CVE references get cross-matched against the KEV catalog. Actively exploited items are flagged on arrival.
A public page per CVE
Every CVE we've seen has a shareable URL with NVD + EPSS + KEV + OTX + source consensus + timeline + the articles that mentioned it. Try /cve/CVE-2026-45585.
BYOK AI daily brief
Drop in an Anthropic or OpenAI API key, get a 300-word brief of the day's most important items, tuned to your focus area.
Two-pane reader, vim keybinds
List on the left, reader on the right, draggable divider. j/k to nav, o to open, b to bookmark, T for MITRE coverage, S for stats.
No telemetry. No proxy.
Single binary, SQLite local state. Nothing leaves your machine unless you explicitly click out. Open source under MIT.
